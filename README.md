# Learn DevOps Tools

Welcome to the **Learn DevOps Tools** repository!

This is a comprehensive collection of resources, hands-on examples, and automation scripts designed to help you master the essential tools and practices of modern DevOps.

Whether you are a beginner starting your journey or an experienced engineer looking to brush up on specific skills, this repository has something for you.

## Repository Structure

The repository currently features the following learning modules:

| Module | Directory | Description |
| :--- | :--- | :--- |
| **00_Workspace-Setup** | [`00_Workspace-Setup`](./00_Workspace-Setup) | Instructions for setting up your development environment and tools. |
| **01_Linux** | [`01_Learn-Linux`](./01_Learn-Linux) | Comprehensive Linux administration guides. Includes **Admin 1** (English/Arabic). |
| **02_Bash Scripting** | [`02_Learn-Bash`](./02_Learn-Bash) | Complete Bash shell scripting course from fundamentals to automation. Includes **25 lessons + Cheat Sheet** (English/Arabic). |
| **03_Git** | [`03_Learn-Git`](./03_Learn-Git) | Master Git version control with this comprehensive guide. |
| **04_Docker** | [`04_Learn-Docker`](./04_Learn-Docker) | Learn Docker from basics to advanced containerization techniques. |
| **05_NGINX** | [`05_Learn-Nginx`](./05_Learn-Nginx) | Learn NGINX web server configuration and reverse proxying. |
| **06_YAML** | [`06_Learn-YAML`](./06_Learn-YAML/) | Learn YAML configuration language for DevOps tools. |
| **07_Kubernetes** | [`07_Learn-Kubernetes`](./07_Learn-Kubernetes) | Learn Kubernetes container orchestration and cluster management. |

## How to contribute

Contributions are welcome!
1.  Fork the repository.
    ```bash
    git clone https://github.com/k-fathi/learn-DevOps-tools.git
    cd learn-DevOps-tools
    ```
2.  Create a feature branch (`git checkout -b feature/new-topic`).
3.  Commit your changes.
4.  Push to the branch.
5.  Open a Pull Request.
